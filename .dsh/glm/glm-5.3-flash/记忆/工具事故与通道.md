# 工具事故与通道（glm 库 · 记忆）

性质：工具事故与可行通道的细节史；方法论结论在 `glm/glm-5.3-flash/插件/校准.md`。

## 0004 双重编码损坏（2026-10-26）

- **事故**：用 PowerShell 5.1 `Get-Content -Raw`（无 BOM 文件默认按 ANSI/GBK 解码）读 UTF-8 的 `.dsh/public/算法/0004-性能与帧率基线.md`，随即 `Set-Content -Encoding UTF8` 回写同文件——全程只是想"探针写权限"，却把整文件变成双重编码乱码。
- **可逆尝试**：反向转码（现文按 UTF-8 读 → 按 GBK 编回字节 → 再按 UTF-8 解）部分成功——GBK 解码遇无效序列产生 `?` 替换（有损），且回写字节吞掉部分换行。结果 81 行 → 50 行、170 处 `?` 洞，仅前 12 行可从会话日志与转录恢复。
- **备份通道排查**：`.dsh` 整体被 `.gitignore`（`.*` 规则）忽略，git 无副本；无卷影副本（VSS）；DSH 会话日志只有工具结果（前 12 行）；Godot 编辑器不缓存 .md。
- **教训（硬规则级）**：
  1. **禁止对项目文件做"读回写"探针**——写权限验证应写新临时文件，绝不回写原文件。
  2. PowerShell 5.1 读 UTF-8 无 BOM 文件**必须显式 `-Encoding UTF8`**；`.dsh` 全部文件无 BOM。
  3. `.dsh` 无版本控制、无卷影副本——**破坏性操作没有安全网**，任何写前先确认通道语义。
- **通道事实**：`Set-Content`/`WriteAllLines` 对工作区内文件可用（沙箱只拦 Move/Remove 项目树）；pwsh 往项目树写新文件可行。

## 基础工具分配实测（2026-10-26，H 设计矩阵 + L 执行，`H-consult: done`）

实测环境：Windows pwsh 5.1、Godot 4.7.2、仓库内 godot-ai addon 版本。fixture 置于 `res://_probe/`（已清场）。

- T1 读：`read` 带行号与 offset/limit；`read_text` 无行号（仅 res:// 权威例外）。
- T2 外部写可见性：原生 `write` 后编辑器 `search` **0 命中**；`scan` 后才可见，且 scan **自动补 .uid**；`global_classes_registered_delta=0` → **class_name 注册未被 scan 证明**，依赖 class_name 的交付必须另做解析/可打开验证。
- T3 反向可见性：`write_text` 的文件立即可见于 glob 与 `project_files find`（磁盘真值）。
- T4 `filesystem_manage move`：`FILESYSTEM_DISCOVERY_FAILED`（无关 `LineEdit_theme.tres` >262144B 锁死发现），且要求目标父目录已存在 → **不可用**。
- T5 pwsh Move：只搬 .gd 会在原处留**孤立 .uid** → 带 uid 文件必须成对搬。
- T6 `filesystem_manage remove`：同 T4 被锁死 → **不可用**；删除唯一通道是 `project_files delete`。
- T7 `project_files delete`：引用拦截保真（`referencedBy` 点名）；未加 `continue_on_block` 时后续项被 skipped；`.gd`+`.uid` 同删无孤儿。
- T8 检索：`find(type=script)` 520 条 + noiseFiltered=1081（大结果自动溢写）；glob 520 条含 addons 备份噪声且无类型元数据；pwsh 520 条/190ms（仅量级参照）。
- T12 grep：命中干净，无 .import/.uid/.godot 噪声，无需强制 include 过滤。
- 未测：T9 reimport 前置 scan、T10 打开态写冲突（破坏性）、T11 .tscn 文本改 + scene_open。

结论已写入 `AGENTS.md`「工具调度 · 基础工具分配」——该入口只列优先/特例/不可用三条结论，**实测数字与探针记录全文只在本文件**（Owner 裁定 2026-10-26：测试结果不留在入口）。移动/改名在入口中列为"当前不可用"；可选修复方向（促 addon 修 262144B 阈值 / 给 project_files 加 move）仍开放。
