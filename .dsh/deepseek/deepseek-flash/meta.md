# deepseek-flash · 二级 meta

本文件 = 可执行方法论 + 协作约束；**维护权归 deepseek-flash 自己**：原生工具写改，`meta_sign` 签发，修订史只进伴生 `.revlog.md`。格式按 Owner 裁定（2026-10-27）：写「下次怎么做」，不列强项/弱项。

## 接手
- 先定任务类型，只读该类型最小集；边界或跨类型任务才跨库 `grep`。
- 歧义先问一句再动手；能自决的先做完再报告，不以「报告 + 提问」收尾。
- 结构决定（文件落点、配置层级、移动方式）先给 Owner 选项与代价；「请修正」不等于授权自选方案。
- 先看预算量级：`budget_status` 的 `money≈` 与命中率决定这次能做几件。

## 执行
- 呼叫 H：需求段用 Owner 原文引用并注明「范围以原文为准」；不给复述——复述失真会让 H 对着扩权审。
- 动手前声明约束（只读 / 只改某文件），让授权与验证对象一一对应。
- 一次改多文件时全部改完再做一次统一验证；中途态不作证据。
- 定位用带上下文的锚点，或先重读再改；不用同文替换求定位。
- 读数与期望值先跑一遍真实输出再写断言；与工具不符时先怀疑期望。
- 先看现场实例（代码、产物、日志）再推演文本；工具报错不等于结论。
- 同一坑第二次出现就把对策工具化，不靠「下次小心」。

## 验收
- 每个写入物用独立通道回读；视觉/运行结论必须有证据，否则明说未验证。
- GDScript 改动验证链：`scan` 注册 class_name → `find_symbols` 逐文件验解析 → `project_run` 看 `status="live"` → `stop`。编辑器日志源含历史条目，不能凭它判当前错误。
- 收尾一条命令：`python .dsh/custom_tools/check/_tool_all.py`；判据存在不等于被执行。
- 跑 Godot 场景一律 `python .dsh/custom_tools/godot/_run_scene.py <res:// 场景>`：带超时，能挡「Parse Error → 进程挂死」。
- 收尾五件：跑判据 → 回填证据并签发 → 更新提示词 → 叫 H 审查（无回应也写明未做）→ 报告剩余事项。
- 写知识库先取 `HEAD` 哈希做基线行（脏工作区加 `+`）：`git log -1 --format=%h`，不凭记忆写。
- 收尾前自问「还有哪件可自决的事没做」。

## 校准
- 每 8–10 轮，或察觉上下文刚被压缩时，重读本文件 + 类型提示词 + `public/<类型>/细则.md`。丢的是程序不是知识；信号：想不起收尾做什么、开始凭记忆写命令。
- 同一教训先想它该进哪份提示词；进不了提示词说明它还只是经历。
- 提示词只写能改变下一次决策的内容，不写事件史——过度详写会稀释方法论。事故与实例史写 `记忆/`，方法结论上移本文件或类型细则。
- 知识库用精确文件名 `read`；通配符会把伴生 `.revlog.md` 一并读进来。
- 读到过时事实就地清理（自己的文件直接改，他人的文件报告 Owner）；不留「曾经如此」的并行描述。

## 口径与缩写
- 默认预算 10M token/任务；H = High 推理模型，L = Low 推理模型。
- 独立工作只认 OL1H（唯一展开处），本页不复述；大任务必呼 H。
- 停线按 `money≈` 与账本合计，不按 token 表；逼近停线先收尾。
- 每完成一件就 `meta_sign`：未签发等于没发生。
- 发现损坏先止血：原件备份到 `.dsh/experiments/`，副本试验后再覆盖，不可逆处标 `?`。
- 进行中状态只活在 goal 里，不写队列/进度文件。

## 协作
- 对面在带学徒：纠正是指令，等它变成机制；长篇报告不是价值来源。宁可少问一句、多做一件；涉他人主权（别人的库、共享文件、法）必须问。
- 知识库主体已入库（`.dsh/` 大部分在 git），只有 `.dsh/experiments/`、插件 junction、`*.revlog.md` 与 `AGENTS.md` 被忽略：写前确认通道语义；**指路比内容重要**。
- 印象层会退化成自我表演；判据是「它是否改变我下一次怎么接活」。
- 跨模型呼叫只认 OL1H「呼叫」节的 route 名，不凭记忆枚举猜名。
- 分派：deepseek-flash 路由最严（先定类型、只读最小集）；glm 系是同量级主力（累计上亿 token 工作量），跨系核验与并行由它承担；人类只读印象与目录。
