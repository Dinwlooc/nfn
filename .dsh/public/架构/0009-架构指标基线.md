## 六、口径与局限

1. **叶子**：方法体不调用本文件内其他方法（可调引擎 API 与外部依赖）。
2. **安全性**：静态（无实例状态）+ `@pure` + `@external` + `@internal` + 未标注且无写入，占方法总数。
3. **风险率**：未标注且按方法体确认写了自身或入参的方法占比。
4. **LCOM**：CK 定义——不共享成员的方法对减去共享对数（负值按 0）；纯转发类天然偏高。
5. **依赖网**：剥离注释与字符串后按 `preload`/`extends`/大写标识符取边；类型标注也算依赖，故为**上界近似**。本节只跑了类型声明网口径；调用网需另跑 `_tool_arch_callgraph.py`。
6. **传播成本**：静态可达对 / N(N-1)，不是真实变更传播（后者需 git 历史）。
7. 排除 `addons/`（第三方）与 `Unused/`（`.gitignore` 归档）。
8. **本次测量含未提交改动**：工作区有 Owner 的 Agent 模块 WIP，以及本轮新增的群体攻击命令/阶段/请求命令 3 个 `.gd`（约 24 个方法），因此文件与方法数略高于 2026-10-18 快照。
9. **已知漂移**：本文件表格是"1483 个非生命周期方法"那一刻的快照；此后又新增了 `RenderAreaAbility`、`GroupAttackNotify` 等代码。**当前工作区实测为 `files=191 / methods=1658 / non_lifecycle=1501 / static=232 / leaf=1015 / leaf_pct=67.6`**（2026-10-27 复跑）。这一行由 `_tool_arch_drift.py --update` 维护，不要手改；重跑工具后数字会小幅上移，引用前请以工具输出为准，不要直接引用本表。
