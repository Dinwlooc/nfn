# 0022 实验架构：AL1H 与 AL2H

keywords: AL1H,AL2H,自主巡航,H席位分档,实验架构,可用模型约束,L席位,临时编排

**这两套都是实验性编排，不是常驻规则**：OL1H 仍是唯一策略（`public/meta/OL1H策略.md`），本文只记录在特定约束下试过的两种扩展，随时可被推翻或替换。入口文件（OL1H 策略、AGENTS 等）不写它们，只由本类型细则按需引用。

## AL1H —— Owner 缺席时的自主巡航

**来由**：Owner 2026-10-27 离场做 AGI 测试，授权"自己找事、自己更新元层、把钱花光再停"。

- **代行边界**：可自选任务、自建分支、自改本库与 `public/` 知识；**不得**改 `NFN-AIGC规则-*.md`（法层）、不得代改他人模型库正文、不做不可逆删除或对运行中编辑器的破坏性操作。
- **停线自判**：预算耗尽即停；预算远未耗尽但每元产出明显下降时也停，写清剩余队列，不刷量。
- **分支纪律**：`.dsh/` 被 git 忽略，元层改动不需要分支；一旦改项目代码先开自己的分支，不动 master 与工作区里他人的未提交改动。
- **验收不变**：证据、回读、`H-consult` 回执、三大代码工作的 H 终审义务全部照旧——自决不等于自证。
- **实测记录**：一轮跑了约 ¥2–4，产出两个校验器、一次知识库格式重构、一个游戏命令实现；暴露的失败模式是"选轻活充数"与"把方法写成散文没有失效条件"。
- **适用/失效**：Owner 常驻时不适用；一旦把 Owner 的判断长期外包给模型而无人复核，即失效。

## AL2H —— H 席位分档

**来由（当时的约束，不是通则）**：2026-10-27 本 harness 的 `list_subagent_models` 只有 `deepseek-flash` 与 `deepseek-v4-pro` 两个可用强模型，glm 系不在路由内。于是约定"本模型的高 effort 版本"顶一般审查、"pro"顶深度推理。

- **选 H 的一般判据**（与"同不同族"无关）：①**能力**——问题属于哪种推理（边界/漏项/实现审查 vs 跨层因果/架构取舍）；②**单价**——按 `budget-watch` 三档实价算单次成本；③**可用性**——`list_subagent_models` 现探，不猜名。
- **本次档位**：H-flash = 同 `provider`+`model` 加 `reasoning_effort=high|max`，做边界分析、契约漏项、实现级代码审查（默认席位）；H-pro = `deepseek-v4-pro`，做跨层因果、架构取舍、"想错一次要赔掉一整段工作"的判断。
- **成本实测**：一次 H-pro 审查 = hit 178k / miss 66k / out 17.6k ≈ **¥1.17**；Pro 相对 flash 的 miss 价 4.4×、out 价 3.3×；同期 L 自己的两小时产出 ≈ ¥3.87。一次 Pro 审查约占其三分之一。
- **防自审不取消**：H-flash 与 L 同模型，只能"找漏/找边界"，不得充当三大代码工作的结论性终审；终审由 H-pro、其他系，或 L 附机器证据承担。
- **回执**：`H-consult: done(h-flash|h-pro)`，必须写席位。
- **失效**：可用模型集一变（出现更强或更便宜的模型），档位必须按三条判据重算，不许沿用 flash/pro 二分。
