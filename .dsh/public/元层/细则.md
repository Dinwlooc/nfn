# 元层 · 细则（公共层）

keywords: 元层细则,元层约定,私有方法,公共知识,更新时机

## 做法

- 任务类型判定与协作维度的唯一展开处：`.dsh/public/meta/分类标准.md`（meta_route 必读第一件）。
- 人读入口：`.dsh/public/meta/元层索引.md`；成员与写权限：`.dsh/public/meta/成员与权限.md`（同在 public/meta/，全类型强加载）。
- 项目任务类型注册表（机读）：`.dsh/meta/tasktypes.json`（active/removed；removed=墓碑：目录保留、不路由）——模型经 `meta_tasktype` 自助登记/移除；签发配置 `.dsh/meta/config.json`（revlogEntries，默认 8，模型可改）。旧 `registry.json`（模型登记）已于 v3 退役。
- 元层结构改动（目录、路由、索引、插件化元工具）先经 Owner；元层文件用原生 read/write/edit 维护，**写后 `meta_sign` 签发**（revisionBasis 必填；时间戳+模型+sha8 自动入伴生 `.revlog.md`）。
- 文本编码统一 UTF-8 无 BOM；写正文前自查无 BOM，改完抽验中文可读。
- 全类型强加载提示词住 `public/meta/`（公共）与 `<系>/<模型>/meta/`（模型通用方法）；中文"元层"只指任务类型。「协作」不是任务类型，是叠加维度：协作方法在各自二级 meta 与 OL1H 策略，原协作类知识已并入 `public/元层/`，类型已入注册表墓碑。

## 知识库维护（判据 + 纪律）

- **署名只走印章**：正文不写 `**署名**` / `**补充署名**` / 修订史（`_tool_papers.py` 会 FAIL）；作者与时间进伴生 `.revlog.md`。删落款前先看括号里有没有夹带规则——落款括号常夹着真正的规则条文。
- **快照类文档带漂移条款**：数字以工具输出为准；`0009` 的实测行由 `_tool_arch_drift.py --update` 维护，不手填。
- **判据范围就是它的价值观**：死指针只查 `public/`；私人 `记忆/`、`experiments/` 归档、他人库不查——查全部会逼人改写历史。
- **写指标文档前先读工具源码**：`agg()` 一句话能否掉记忆里的三个"定义"。
- **编码事故的唯一恢复通道**：.NET `Encoding.GetEncoding(936)` 把 mojibake 重新编码回字节再按 UTF-8 解码（Python `gbk` 缺 PUA 映射）；不可逆处标 `?`，不猜字补全。防复发 = 校验器的 mojibake 判据 + 禁止"读回写"探针。
- **校验器纪律**：每个判据都要有"坏样本 → FAIL"的夹具，只报 PASS 等于没有；夹具要在写进文档**之前**跑；新工具先查 `custom_tools/README.md` 防止重复实现。
- **进行中状态只在 goal 里**，文件系统只放提示词库与知识库：不写队列、进度、缓存文件。
- **指纹口径**：报花费用 `tools/_tool_budget.py --stop <¥>`，看 `STOP total / left / used%`；口径是**账本合计**（含子代理与其它会话），不是"本会话"；停线按 ¥ 不按 token。
