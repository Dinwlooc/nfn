# 自动 · 细则

keywords: 自动任务,自主巡航,任务自选,停线,无人值守

## 这个类型是什么

Owner 不在场、或明确说"改成自动"时，会话按本细则自己找活、自己验收、自己收尾，**不等 Owner 点名**。

## 自选任务的顺序（优先级从高到低）

1. **修真实缺陷**：会让项目/知识库出错或崩溃的问题（编译失败、死指针、规则错实现）。
2. **推进设计书待办**：按设计书"待办事项"取一件，挑**能在本会话内闭环并验证**的最小切片。
3. **补机制**：把重复的人工判断变成机器判据（校验器、护栏、探针）。
4. **整理与减法**：删落后工具、并重复知识、清死指针。

四类都空时停手，不刷量。

## 纪律

- **一次一件**：选定的任务只存在于 goal / 会话里，做完验收再换下一件；不并行三件以上。
- **progress 不落盘**：**文件系统只放提示词库与知识库**；待办、进度、临时清单不进文件——进行中状态由 goal 承载，成果与证据写成知识。不要在项目树里造队列/缓存文件。
- **验收先于宣布**：能用机器判据的（编译、校验器、headless 启动）必须跑；不能的明说"未验证"。
- **H 席位按能力 → 单价 → 可用性三条选**：当前只有 flash 与 pro 可用，边界/漏项用本模型 `reasoning_effort=high`，深度推理才用 `deepseek-v4-pro`；防自审不取消，H-flash 不得当三大代码工作的终审。
- **停线**：预算超额即停；预算充足但每元产出下降（重复劳动、无新信息）时也停，把剩余事项写进报告（不写文件）。
- **异常即记**：工具报错、假通过、数字对不上、环境限制、自己的判断被推翻——**当场**写进 `记忆/`，四要素＝现象 / 证据（命令、输出、文件:行）/ 影响 / 绕法；写完 `meta_sign`。常见假通过：`--check-only --script` 在依赖编译失败时仍返回 0。
- **笔记**：每轮至少写一条可检索的**知识**（做成了什么、凭什么算做成、踩了什么坑），写完 `meta_sign` 签发。
- **收尾一条命令**：每轮结束跑 `python .dsh/custom_tools/check/_tool_all.py`（知识库格式 / 死指针 / 基线漂移三合一），全绿再宣布完成；改了 `.gd` 另加 `godot --headless --path . --quit-after 150` 数 `SCRIPT ERROR`。

## 收尾五件（每轮结束必做，缺一件就没收尾）

> 通用动作（校准、收尾五件、凝练周期、预算口径）的常驻版本在模型 `meta.md`「通用自检与校准」一节；本节是自动类型下的展开。改一处时两处都要对。

1. **跑判据**：`_tool_all.py` 全绿；改过 `.gd` 再加 headless 启动数 `SCRIPT ERROR`。
2. **回填证据**：把命令输出/计数/EXIT 写进 `记忆/` 的知识条目，`meta_sign` 签发。
3. **更新提示词**：改过做法、遇到新坑、发现判据失效，就当场改 `public/自动/细则.md` 与本模型命名提示词 `deepseek/deepseek-flash/自动/deepseek-flash.md`。**提示词是最重要的产物**——这一轮的教训如果进不了提示词，下一轮就要重交学费。
4. **叫 H 审查**：把本轮结论（做了什么、证据是什么、还有什么没验证）交 H 席位复核，尤其涉代码结构、规则语义、判据是否真能证伪。自审不能替代。H 无回应/预算不足时，必须在报告里写"未做 H 审查"及原因，不能默默跳过。
5. **报告剩余事项**：写明剩什么、为什么停、需要 Owner 什么（不写进度文件）。

## 长对话的定期校准

上下文被压缩或轮次很多时，**最容易丢的正是"我该按什么程序办事"**（提示词、席位纪律、收尾五件）。所以：

- 每 **8–10 轮**、或每次察觉到上下文刚被压缩后，**先重读**：本文件 + `deepseek/<模型>/meta.md` + `deepseek/<模型>/<类型>/<模型>.md`，再继续干活。
- 判断"是否该校准"的信号：突然想不起收尾该做什么、开始凭记忆写命令、把"等 Owner"当停手理由。
- 校准结果要么体现在提示词修订里，要么体现在下一轮的行为里；两者都没有，就等于没校准。

## 记忆库的凝练周期

- 记忆库是**用来校正方法论的**，不是仓库：每 10 轮或记忆文件 >8 个时，做一次合并/删除；方法结论上移到类型细则，实例与专名留在记忆。
- 判据：读者第一次打开 `记忆/` 时，能否在 3 个文件内找到"上次做到哪、怎么验证的"。
